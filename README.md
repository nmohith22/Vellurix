# Vellurix

An offline-first Android reader for EPUB, PDF, TXT, HTML, FB2, and basic RTF. It includes a responsive library, customizable reading themes, and resizable book and shelf widgets.

## Download

**[Download Vellurix 0.1.2 for Android](https://github.com/nmohith22/Vellurix/raw/refs/heads/main/release/Vellurix-0.1.2.apk)**

Download the APK on your Android device, open it from Downloads, and follow Android's install prompt. Install it over your existing Vellurix app without uninstalling first to keep its local library, shelves, settings, widgets, and reading progress. Android may ask you to allow your browser or file manager to install apps from that source.

## Features

- Read EPUB, PDF, TXT, HTML, FB2, and basic RTF files.
- For EPUB and flowing text, set global reading defaults or per-book overrides for themes, text and page colors, fonts, and text size. Unset per-book settings inherit the global defaults, and each book can be reset to those defaults.
- Choose paper, white, sepia, night, forest, slate, or independently customize text and page colors with a live preview. PDFs retain their document page appearance.
- Adjust text size and font; restore an EPUB's publisher font with **Publisher default**.
- Choose no transition, fade, slide, or page-turn animation.
- Scan a folder when requested, create shelves, and add book or shelf widgets to the home screen.
- Adapts to phones and foldable displays.
