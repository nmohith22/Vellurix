# Vellurix

An offline-first Android reader for EPUB, PDF, TXT, HTML, FB2, and basic RTF. It includes a responsive library, customizable reading themes, and resizable book and shelf widgets.

## Download

**[Download Vellurix 0.1.10 for Android](https://github.com/nmohith22/Vellurix/raw/refs/heads/main/release/Vellurix-0.1.10.apk)**

Download the APK on your Android device, open it from Downloads, and follow Android's install prompt. Install it over your existing Vellurix app without uninstalling first to keep its local library, shelves, settings, widgets, and reading progress. Android may ask you to allow your browser or file manager to install apps from that source.

## Features

- Read EPUB, PDF, TXT, HTML, FB2, and basic RTF files.
- For EPUB and flowing text, set global reading defaults or per-book overrides for themes, text and page colors, fonts, and text size. Unset per-book settings inherit the global defaults, and each book can be reset to those defaults.
- The reader opens in a distraction-free view. Tap the center to reveal controls; tap either side to change pages. The compact toolbar provides themes, rotation, contents, and bookmarks; swipe from the left edge to open the book drawer.
- Choose paper, white, sepia, night, forest, slate, or independently customize text and page colors. PDF documents retain their page colors.
- Adjust text size or zoom, enable two-column EPUB pages, and choose a typeface. Appearance selections update immediately, and EPUB column changes keep the current reading position. Restore an EPUB's publisher font with **Publisher default**.
- Choose no transition, fade, slide, or animated page turn.
- Choose from 19 Monkeytype-inspired app themes adapted from the local `workout_app` palette.
- Tap a book card or list row to read it. Choose card covers with or without titles; list rows always show both. EPUB/PDF files are retried from a private cache if a storage provider cannot serve the reader directly. Long-press to assign a shelf or remove a book.
- Switch the library between card and list views, resize the items, and change the app theme from Settings.
- See embedded EPUB covers and first-page PDF previews in the library; each card and row picks up a tint from its cover.
- Scan a folder when requested, create shelves, and add book or shelf widgets to the home screen.
- Adapts to phones and foldable displays; the reader hides system bars and reveals them temporarily on a swipe.
